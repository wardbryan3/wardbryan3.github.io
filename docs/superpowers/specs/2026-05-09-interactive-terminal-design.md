# Interactive Terminal Spec

## Summary

Extend the fastfetch hero window into an interactive terminal shell. After the initial animation, the prompt becomes a live input field accepting commands. On subpages, the terminal moves to a collapsible right sidebar.

## Commands

All commands are case-insensitive. Unknown commands show `command not found: <name>`.

### Universal (work on every page)

| Command | Args | Behavior |
|---------|------|----------|
| `help` | — | Lists all available commands with one-line descriptions |
| `whoami` | — | Shows about info (name, status, level, focus) |
| `pwd` | — | Shows current page path (e.g. `/home`, `/blog`) |
| `date` | — | Shows current date/time |
| `echo` | text... | Echoes arguments back |
| `clear` | — | Clears command history from display (prompt stays) |
| `history` | — | Shows previously typed commands this session |
| `neofetch` | — | Re-runs the initial fastfetch system info display (tux + fields) |
| `ls` | [path] | Lists available sections. On subpages, lists page content |
| `cd` | path | Navigates to a page: `cd blog` → links to /blog |
| `cat` | file | Page-specific content viewer |
| `find` | keyword | Searches all posts/projects by title/name |
| `grep` | keyword | Full-text search across all blog posts and projects |
| `top` | — | Fun htop-style ASCII display with site stats |

### Page-Specific Overrides

| Page | Command | Behavior |
|------|---------|----------|
| /blog | `ls` | Lists recent blog posts |
| /blog | `cat` <slug> | Opens specific blog post |
| /projects | `ls` | Lists projects |
| /projects | `cat` <slug> | Opens specific project |

### Search (`find` / `grep`)

- Build-time generated `SearchData.json` containing all posts and projects: `[{title, path, type, content, tags}]`
- Generated by an Astro integration or build script that reads content collections at build time
- Embedded as a static JSON file in `public/`, fetched or imported client-side
- Client-side in-memory search, no server dependency
- `find` matches against titles/names only
- `grep` full-text search with matched line + file reference output

## Layout

### Homepage (`/`)
- Terminal is the full hero section (current `.hero-dashboard` position), centered, max-width 780px
- Window opens with grow animation → `bryan@ward:~$ fastfetch` types out → output appears → prompt becomes interactive

### Subpages (`/blog`, `/projects`, etc.)
- Terminal moves to a collapsible right sidebar
- Fixed position, width ~380px, full viewport height
- Open by default on first visit, dismissible
- Minimize button inside the terminal (top-right corner icon)
- Keyboard shortcut: `Ctrl+K` to toggle sidebar
- On open: shows compact header with `pwd` output, then `ls` listing
- The fastfetch animation does NOT play on subpages

## Architecture

```
src/terminal/
  commands.js          — command definitions (universal + page factory)
  CommandRegistry.js   — registry: register, resolve, execute, history
  Terminal.jsx         — interactive terminal UI (replaces FastfetchWindow)
  SearchData.json      — build-time generated (from Astro content collections)
```

### Data Flow

1. `Terminal.jsx` renders the window (grow animation on homepage), manages input state
2. User types command, presses Enter
3. `CommandRegistry.execute(cmd, args, context)` resolves the command by name
4. Command handler returns `{ output: ReactNode, action?: 'navigate', url?: string }`
5. Output appends to display history, navigation actions open links
6. History buffer tracks all commands

### Command Registry

- Universal commands registered on init
- Page-specific commands merged via `pageOverrides` prop
- Context object passed to handlers: `{ page: string, history: string[] }`

### Terminal States

The `Terminal` component has phases:
- `growing` → `prompt` → `command` → `output` → `interactive` (homepage only)
- `interactive` (subpages start here)

## CSS

- Terminal window: keep existing `.terminal-window` styles
- Sidebar: new `.terminal-sidebar` class — fixed right, 380px wide, 100vh, z-index below nav, scrollable command history area
- Minimize button: `.terminal-minimize` — positioned top-right, small icon
- Sidebar collapsed state: `.terminal-sidebar.collapsed` — translate out or shrink to a tab
- Input line: `.terminal-input` — the interactive prompt row with blinking cursor

## Props

`Terminal` accepts:
- `page` (string) — current page path, e.g. `/`, `/blog`
- `pageOverrides` (object, optional) — `{ ls, cat, ... }` for page-specific commands
- `projectCount` (number)
- `postCount` (number)
- `searchData` (array, optional) — for find/grep on pages that reference them

## Responsive

- On mobile (<768px): sidebar collapses to full-width overlay below nav instead of sidebar
- Terminal on homepage: same responsive behavior as current (tux hidden at 480px)
